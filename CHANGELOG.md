# Changelog

## 2.0.0

- Complete UI rebuild with React + TailwindCSS
- 8 crosshair shapes: Cross, Dot, Circle, T-Shape, X-Shape, Cross+Dot, Circle+Dot, Circle+Cross
- 6 built-in presets: Classic, Dot, Sniper, Minimal, T-Style, X-Mark
- Custom presets: save, load and delete up to 10 personal presets
- Full customization: color, outline, thickness, length, gap, opacity, dot toggle and size
- Dynamic crosshair: reactive expansion/shrink based on movement, sprint and aiming
- Import/Export system: share crosshair configs via encoded string
- Keybind support: open UI, toggle crosshair, cycle presets (all remappable in FiveM settings)
- Client-side persistence via KVP (survives reconnects and restarts)
- Live preview in the customizer UI

## 1.0.0

- Initial release
- Basic crosshair style
- Persist saved crosshair
- Reset functionality
